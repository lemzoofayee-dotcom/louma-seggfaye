### Action 1 — Créer une page "thiéboudienne" dans guide.seggfaye.com avec schema Recipe complet
**Impact estimé : Élevé | Délai résultats : 6-10 semaines**

"Recette thieboudienne ingrédients" est la requête culinaire sénégalaise la plus recherchée en France. guide.seggfaye.com a caldou, dibi, mbakhalou saloum, lakh — mais la thiéboudienne n'est pas visible dans les SERP, ce qui est un manque majeur. Une page thiéboudienne avec :
- schema Recipe complet (temps, portions, ingrédients avec guedj/netetou/yeet)
- liens vers les produits boutique seggfaye.com
- photo du plat (prérequis pour l'éligibilité rich snippet)

...pourrait capturer du trafic sur la requête la plus volumineuse de la niche et générer des visites boutique directes.

### Action 2 — Corriger l'éligibilité des rich snippets Recipe sur guide.seggfaye.com
**Impact estimé : Moyen-Élevé | Délai résultats : 2-4 semaines après correction**

Les schemas Recipe sont en place mais les rich snippets ne s'activent pas. Étapes concrètes :
1. Tester chaque URL plat dans [Rich Results Test](https://search.google.com/test/rich-results) — repérer les erreurs/avertissements
2. Vérifier que chaque page plat a une image valide (non un fallback logo) — c'est souvent la cause principale d'inéligibilité
3. Vérifier le format ISO 8601 des durées (PT30M, PT1H)
4. Corriger dans le code source — une seule page suffit comme test pilote

Les rich snippets Recipe (images, temps de cuisson) augmentent le CTR de 15 à 30% selon les benchmarks. C'est du trafic gratuit supplémentaire sur les pages déjà indexées.

### Action 3 — Créer un article "Où acheter du guedj en France en 2026" ciblant la longue traine
**Impact estimé : Élevé sur longue traine | Délai résultats : 4-8 semaines**

"Ou acheter du guedj en france" — la requête est dominée par magasin-africain.com et keryaye.fr. Le paradoxe : seggfaye.com vend du guedj mais n'est pas vu sur cette requête. Un article structuré de type "guide d'achat" (où acheter, comment choisir, prix moyens, différence guedj beurre vs guedj ordinaire) avec schema FAQPage et CTA boutique serait un moyen naturel de capturer ce trafic transactionnel sans créer une page de vente directe. Le Guedjologue a une légitimité unique pour écrire cet article.
